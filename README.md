# How to get started

Install Python 3.12 via Scoop
```commandline
scoop bucket add versions
scoop install python312
```

Install pipx
```commandline
python -m pip install --user pipx
```
Add "C:\Users\charl\AppData\Roaming\Python\Python312\Scripts" to your PATH. Relaunch your terminal or IDE.

Install Poetry
```commandline
pipx install poetry
pipx ensurepath
```
Install packages
```commandline
poetry install
```
