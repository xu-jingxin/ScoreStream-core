# How to get started

You need Audiveris

Install Python 3.12 via Scoop
```commandline
scoop bucket add versions
scoop install python312
```

Install pipx
```commandline
scoop install pipx
```

Install Poetry
```commandline
pipx install poetry
pipx ensurepath
```
Install packages with Poetry
```commandline
poetry install
```

Install MiniConda
```commandline
scoop install miniconda3
```

Install packages with Conda
```commandline
conda env create -f environment.yaml
```
